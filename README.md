# Project Setup Guide

This guide will help you set up the project environment and run the application locally.

## 1. Create a Virtual Environment

To create a virtual environment for the project, run the following command:


python3 -m venv venv
source venv/bin/activate


## 2. Install Project Dependencies

With the virtual environment activated, install the required dependencies by running:

pip install -r requirements.txt


## 3. Run the Application

After installing the dependencies, you can run the application using uvicorn. Run the following command:

uvicorn main.py
